# 🐢 Python Turtle Graphics - Colorful Mandala Flower

Welcome to the first project of the **Python Turtle Graphics Series**! 🚀

This project demonstrates how to create a dynamic, symmetrical geometric pattern using Python's built-in `Turtle` module. It combines loops, mathematical angles, and color cycling to render an engaging visual layout.

## 🌟 Key Features
- **Dynamic Color Palette:** Cycle through a predefined array of vibrant colors.
- **Adaptive Pen Thickness:** Incremental pen width adjustment for a 3D visual depth.
- **Loop Logic:** Utilizes a simple `for` loop with angle turns to construct precise geometry.

## 🛠️ Requirements
- Python 3.x (No external installation needed; `turtle` comes built-in with standard Python).
